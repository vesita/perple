# 地面检测基准测试：结论报告

## 概述

在真实世界的 LiDAR 数据集上，针对 **倒装传感器**（Z 轴相对于重力方向翻转）的场景，实现了五种地面检测策略并进行了基准测试（共 29 组参数组合）。本文档总结相关发现，供论文参考。

---

## 1. 测试的策略

| # | 策略 | 机制 | 速度 |
|---|------|------|------|
| 1 | **histogram_expand** | Z 直方图峰值 → 阈值扩展 | ~2ms |
| 2 | **peak_down_expand_up** | Z 直方图峰值 → 向下扫描至阈值 → 向上扩展 | ~2ms |
| 3 | **ransac_ground** | 全点云 RANSAC 平面拟合 | ~20-30ms |
| 4 | **histoseed_grow** | 直方图种子 → 对种子执行 RANSAC → 生长至全点云 | ~8-12ms |
| 5 | **gpf_ground** | SVD 迭代平面拟合（Ground Plane Fitting） | ~8-23ms |

---

## 2. 关键发现：倒装 LiDAR

传感器为 **倒装** 安装：Z 轴指向下方，因此在传感器坐标系中，**地面位于高 Z 值区域**，而车辆自身（车顶、行李架）则处于 Z ≈ 0 附近。

**影响：** 所有基于 Z 直方图的方法最初均告失败——峰值 bin 落在车辆本体而非地面上。只有 RANSAC 成功，因为它具有 **坐标不变性**。

**修复方案（适用于所有策略）：**

1. 处理前对 Z 取反：`z = -z`
2. 从 Z 范围 **底部**（取反后的最低非空 bin）寻找峰值
3. 在每个返回点恢复原始 Z 符号

这一修复将倒装情况转换为标准的"地面在低 Z 处"假设。

---

## 3. 最优配置

| 参数 | 最优值 | 说明 |
|------|--------|------|
| `ground_expand`（直方图） | **0.20** | 控制峰值周围的 Z 范围。过小（<0.10）会在倾斜地面上漏检；过大（>0.30）会引入墙面点。 |
| `ground_ransac_distance` | **0.30** | 点到平面的最大内点距离。0.3 能产生最干净的地面，墙面边界泄漏最少。 |
| `ground_ransac_iterations` | **100** | 对种子区域（~5000 点）进行 RANSAC，100 次迭代足够稳定。 |

**参数敏感性总结：**
- **expand（阈值）：** *关键。* 决定了倾斜地形上的地面召回率。
- **distance：** *中等敏感。* 控制干净度与召回率之间的权衡。
- **iterations：** *不敏感。* 50-200 次结果相似。
- **直方图 bin 数：** *不敏感。* 100-500 个 bin 均可工作。

| 帧号 | 策略 | 参数 | 地面点数 | 质量 |
|------|------|------|---------|------|
| 3 | histogram_expand | expand=0.15 | ~2500 | 良好 |
| 8 | peak_down_expand_up | th=0.05, ex=0.20 | ~2800 | 良好 |
| 11 | peak_down_expand_up | th=0.10, ex=0.20 | ~2800 | 良好 |
| 14 | peak_down_expand_up | th=0.15, ex=0.20 | ~2800 | 良好 |

| 20 | histoseed_grow | seed=0.10, d=0.3 | ~3000 | **最优** |

**关键观察：**
- **expand=0.20** 是所有 Z 基方法的一致最优值
- **histoseed**（帧 20）产生 **最干净的地面**——墙面边界点最少
- **threshold（th）参数无关紧要**——只要 ex=0.20，expand 就主导结果
- 纯 RANSAC 和 GPF 质量相当，但计算成本更高

## 5. 推荐方案：Histoseed 混合策略

```rust
// 最优策略的伪代码
fn histoseed_plane(cloud, distance, iterations) {
    // 步骤 1：Z 直方图种子（快速）
    let (seed_mask, _) = histogram_peak_expand(cloud, expand);
    let seed: Vec<Point> = cloud.filter(seed_mask).collect();

    // 步骤 2：仅对种子执行 RANSAC（有针对性）
    let plane = ransac_fit(seed, distance, iterations);

    // 步骤 3：生长至全点云（距离检查）
    let ground_mask = cloud.iter()
        .map(|p| plane.distance(p) < distance);
    ground_mask
}
```

**优势：**
- **比全点云 RANSAC 快 3 倍**（~10ms vs ~30ms）
- **质量与全 RANSAC 相当**
- **对倾斜具有鲁棒性**（纯直方图方法不具备）
- **调参简单**（只有 expand + distance 起作用）

**原理：** 直方图种子快速剔除了 80-90% 的非地面点（墙面、车辆、植被），使 RANSAC 在干净的小子集上运行。随后的生长步骤恢复被激进种子遗漏的地面点。

## 6. 性能分解（每帧）

| 方法 | 平均耗时 | 方差 | 地面召回率 |
|------|---------|------|-----------|
| histogram_expand | 1.8ms | 低 | ~70% |
| peak_down_expand_up | 1.9ms | 低 | ~72% |
| **histoseed_grow** | **9.4ms** | **低** | **~95%** |
| ransac_ground | 27.1ms | 高 | ~98% |
| gpf_ground | 14.2ms | 中 | ~90% |

*histoseed 在实际应用中提供了最佳的精度-速度权衡。*

---

## 7. 失败模式

| 模式 | 现象 | 受影响的策略 |
|------|------|-------------|
| **倾斜地面** | 地面部分或全部丢失 | histogram, peak_down |
| **墙面边界** | 墙面点被分类为地面 | histogram, peak_down（expand 过大） |
| **种子稀疏** | RANSAC 退化到错误平面 | histoseed（种子太小） |
| **倒装 LiDAR** | 地面在高 Z 处，车体在 Z≈0 | 所有策略（通过 Z 取反修复） |
| **SVD 奇异** | 协方差矩阵退化 → 无平面 | GPF（通过回退法向量处理） |

---

## 8. 论文建议

1. **默认管线：** 使用 `histoseed_grow`，参数 `expand=0.20`、`distance=0.3`、`iterations=100`
2. **倒装处理：** 处理前对 Z 取反；可通过统计测试检测安装方向（若最低 10% 点的 Z 均值 > 最高 10% 点的 Z 均值，则传感器倒装）
3. **运行时优化：** 直方图种子将 RANSAC 输入减少约 85%，从而在嵌入式设备上实现实时性能
4. **局限性：** 所有基于 Z 的方法均假设地面大致水平（±15°）。对于极端坡度，应回退到全点云 RANSAC 或 GPF
5. **未来工作：** 融合 IMU 重力向量以避免 Z 取反的启发式方法；使用时序平滑在帧间稳定地面平面

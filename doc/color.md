# Color模块文档

## 概述

Color模块是Perple项目中负责图像目标检测的核心模块。它使用YOLO模型对输入图像进行目标检测，输出检测到的对象边界框及相关信息。

## 模型输出格式

### YOLO模型输出结构

YOLO模型的输出是一个三维张量，形状为 `[1, num_boxes, num_params]`：

- `1`: 批次大小（目前只处理单张图片）
- `num_boxes`: 检测框的数量
- `num_params`: 每个检测框的参数数量，通常为5个参数

### 检测框参数格式

每个检测框包含5个参数：

1. `x1`: 边界框左上角x坐标（相对于模型输入尺寸）
2. `y1`: 边界框左上角y坐标（相对于模型输入尺寸）
3. `x2`: 边界框右下角x坐标（相对于模型输入尺寸）
4. `y2`: 边界框右下角y坐标（相对于模型输入尺寸）
5. `confidence`: 置信度分数

注意：坐标是相对于模型输入尺寸（默认640x640）的，需要进行坐标转换才能映射到原始图像。

## 检测结果解析机制

### 坐标转换

由于模型输出的坐标是相对于模型输入尺寸的，需要将其转换为相对于原始图像的坐标：

```rust
let scale_x = img_width / input_width as f32;
let scale_y = img_height / input_height as f32;

let scaled_x1 = x1 * scale_x;
let scaled_y1 = y1 * scale_y;
let scaled_x2 = x2 * scale_x;
let scaled_y2 = y2 * scale_y;
```

### 置信度过滤

在处理检测结果时，会根据设定的置信度阈值（默认0.5）过滤掉低置信度的检测框：

```rust
if confidence < confidence_threshold {
    continue;
}
```

### 非极大值抑制（NMS）

为了去除重叠度高的重复检测框，系统使用NMS算法：

1. 按置信度对检测框进行排序（降序）
2. 依次处理每个检测框：
   - 如果当前框未被抑制且置信度高于阈值，则保留该框
   - 计算该框与后续所有框的IoU（交并比）
   - 如果IoU超过设定阈值（默认0.7），则抑制相应框

### 最终存储格式

处理后的检测结果存储在 `ImgBud` 结构中，包含多个 `Detection` 对象，每个对象包括：

- `bbox`: `Box2D` 类型，包含四个坐标值（x1, y1, x2, y2）
- `class_id`: 类别ID（目前只有person类别，ID为0）
- `class_name`: 类别名称（"person"）
- `confidence`: 置信度分数

## 核心组件

### YoloDetector

`YoloDetector` 是核心的检测器类，负责：

1. 加载和管理ONNX模型
2. 设置置信度和NMS阈值
3. 执行模型推理
4. 调用后处理函数

### ImgBud

`ImgBud` 是固定容量的检测结果容器，具有以下特点：

- 预分配固定容量，避免动态内存分配
- 提供类似Vec的操作接口（push, clear, len等）
- 支持迭代器访问

### Box2D

`Box2D` 表示一个二维边界框，包含：

- `x1`, `y1`: 左上角坐标
- `x2`, `y2`: 右下角坐标
- 提供计算宽度、高度、面积等辅助方法

### Detection

`Detection` 表示一个检测到的对象，包含：

- `bbox`: 边界框信息
- `class_id`: 类别ID
- `class_name`: 类别名称
- `confidence`: 置信度分数

## 性能优化

1. **内存管理**: 使用预分配的固定容量容器，避免频繁的内存分配和释放
2. **坐标转换优化**: 直接在原始数据上进行坐标转换，避免不必要的数据拷贝
3. **排序优化**: 使用高效的排序算法对检测框按置信度排序
4. **NMS优化**: 通过提前过滤和面积检查减少不必要的IoU计算

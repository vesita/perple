# Lidar模块文档

## 概述

Lidar模块是Perple项目中负责处理LiDAR点云数据的核心模块。它能够读取点云数据，进行聚类分析，并输出3D边界框。

## 数据结构

### Lifra

`Lifra` 是点云数据的容器类，用于存储和管理点云数据：

- 使用预分配的Vec存储点云数据，避免动态内存分配
- 提供点云数据的基本操作（push, clear, len等）
- 支持迭代器访问
- 实现点云数据过滤，自动排除NaN和无穷大的无效点

### Box3D

`Box3D` 表示一个三维边界框，用于包围点云中的对象：

- `x_min`, `x_max`: X轴的最小和最大值
- `y_min`, `y_max`: Y轴的最小和最大值
- `z_min`, `z_max`: Z轴的最小和最大值
- 提供计算体积、IoU、包含关系等辅助方法

### LidBud

`LidBud` 是固定容量的3D边界框容器，用于存储聚类结果：

- 预分配固定容量，避免动态内存分配
- 提供类似Vec的操作接口（push, clear, len等）
- 支持迭代器访问

## 处理流程

### 点云读取

1. 使用`pcd-rs`库读取PCD格式的点云文件
2. 过滤无效点（NaN和无穷大值）
3. 将有效点存储到`Lifra`容器中

### 聚类分析

聚类处理流程如下：

1. 清空历史聚类结果
2. 遍历所有点云数据点
3. 对每个点进行聚类处理：
   - 查找附近的现有聚类
   - 如果找到合适的聚类，则将点添加到该聚类
   - 如果未找到合适的聚类，则创建新的聚类
4. 执行最终的聚类合并操作，合并相近的聚类
5. 将结果写入输出流

### 聚类参数

聚类算法使用以下关键参数：

- `CLUSTER_DISTANCE_THRESHOLD`: 聚类距离阈值，决定点与聚类间的最大距离
- `CLUSTER_MERGE_THRESHOLD`: 聚类合并阈值，决定两个聚类是否应该合并
- `MIN_POINTS_PER_CLUSTER`: 每个聚类所需的最小点数

## 输出格式

### 3D边界框

聚类结果以3D边界框的形式输出，每个边界框包含：

- `x_min`, `x_max`: X轴范围
- `y_min`, `y_max`: Y轴范围
- `z_min`, `z_max`: Z轴范围

### 输出容器

处理结果存储在`LidBud`容器中，该容器具有以下特点：

- 固定容量，避免动态内存分配
- 提供标准的集合操作接口
- 支持迭代器访问

## 性能优化

1. **内存预分配**: 所有容器都预分配固定容量，避免运行时内存分配
2. **无效点过滤**: 在读取阶段就过滤掉无效点，减少后续处理负担
3. **高效聚类算法**: 使用空间索引和距离计算优化聚类过程
4. **聚类合并**: 通过合并相近聚类减少最终输出数量

## 可视化支持

使用`rerun`库支持点云数据的3D可视化：

- 可以显示原始点云数据
- 可以显示聚类结果和3D边界框
- 支持交互式查看和分析

## 3  PruneQt：基于四叉树剪叶的自适应密度聚类方法

### 3.1  问题背景与难点分析

后聚类策略是感知处理流的关键输出环节，为跟踪器提供点云障碍物信息。LiDAR 点云
近密远疏的非均匀分布使固定参数的聚类算法面临两难：小参数在远处召回不足，大参数
在近处造成粘连欠分割。室内多行人密集行走时，这一问题尤为突出——当多个行人近距离
并行或交错，其对应的点云在三维空间中连为一体，难以通过纯几何方法有效分离。

LV-DOT 采用先体素占用过滤再 DBSCAN 的两阶段方案[5]，但固定分辨率的体素网格无
法自适应密度变化：近处行人区域体素过细造成冗余计算，远处行人区域体素过粗导致目
标丢失。上述问题的核心在于：聚类算法需要自适应的空间分区能力来匹配 LiDAR 的非
均匀密度分布。

### 3.2  算法设计

PruneQt 的处理流程分为两个阶段。

**第一阶段——四叉树构建与剪叶过滤。** 将非墙面点在 XY 平面上构建四叉树，递归细分
直至叶节点包含的点数低于 $N_{\min}$ 或达到最大深度 $D_{\max}$。四叉树的自适应分区
特性使密集区域获得更精细的叶子划分，稀疏区域保持较大的叶子范围。遍历所有叶节点，
仅保留点数 $\geq N_{\text{keep}}$（默认 4）的密集叶节点，以叶内点的质心坐标代替
整叶所有点。稀疏叶节点被丢弃——即剪叶——相当于同时完成了噪声滤除与数据降采样。

相比固定分辨率的体素网格，四叉树剪叶的自适应分区能更好地匹配 LiDAR 的点云特性：
近处行人区域自动生成细小叶子，保留精细空间分辨率；远处行人区域叶子范围自动扩大，
避免目标被过度分割。

**第二阶段——四叉树加速 DBSCAN。** 在叶质心点上构建第二棵四叉树，作为 DBSCAN
的空间索引。范围查询时利用四叉树的分层包围盒快速剪枝不相交分支，将邻域搜索复杂
度从 $O(n^2)$ 降至 $O(n \log n)$。

#### 结论

- **全局最优：depth=6, occ=5**（F1 **0.7841**，FP **46**，基线 FP 147 的 **69% 降幅**）
- **`min_occ` 是核心控制杆**：occ=4 → 高 Recall 高 FP；occ=5 → 最优 F1；occ=6+ → Recall 崩溃
- **depth 影响小**：occ=5 下 depth 跨 5→7 仅差 0.013 F1
- 耗时稳定在 17.1-17.9s，主要由 YOLO 推理主导

PruneQt 与 LV-DOT[5] 的两阶段聚类方案在整体框架上相似——均采用"先过滤降采样、
再密度聚类"的级联结构。区别在于空间分区方式：LV-DOT 使用固定分辨率体素网格，
PruneQt 以四叉树自适应分区替代固定网格，使过滤粒度随点云局部密度自动调整；相应
地，DBSCAN 阶段的邻域搜索借助四叉树索引将复杂度从 $O(n^2)$ 降至 $O(n \log n)$。

### 3.5  自适应深度分裂（SplitPolicy trait + log₂ 衰减）

将四叉树分裂决策抽象为 `SplitPolicy` trait，新增 `AdaptiveDepthPolicy`：

```
target_res(r) = res₀ * (1 + β * log₂(1 + r / r₀))
```

其中 $r$ 为节点中心到传感器的距离。log₂(1+·) 形式在 $r=0$ 处自然为 0，无需条件分支。
参数含义：

- `res₀` — 基准分辨率（米），$r \leq r₀$ 时的目标叶子对角线长度
- `r₀` — 基准距离（米）
- `β` — 增长系数；$\beta = 0$ 退化为恒定分辨率，$\beta = 0.2$ 时 $r=2r₀$ 处分辨率粗化约 1.2 倍

**默认方法**：当前版本默认启用自适应深度（`adaptive_depth = true`），参数为 β=0.2,
res₀=0.04, r₀=2.0, max_depth=12。可通过 `--cluster-toml 'adaptive_depth=false'` 回退到
固定深度模式，或通过 `adaptive_res0`/`adaptive_r0`/`adaptive_beta` 调参。

### 3.6  自适应深度 vs 固定深度

在 408 帧数据集上对比（统一使用 occ=5）：

| 方法 | P | R | F1 | FP |
|:----|:-:|:-:|:-:|:-:|
| 原始基线 (depth=10, occ=4) | 85.1% | 68.7% | 0.7604 | 147 |
| 固定最优 (depth=6, occ=5) | 94.7% | 66.9% | 0.7841 | 46 |
| 自适应 (β=0.2, occ=5) | 94.5% | 66.5% | 0.7808 | 47 |

自适应深度在此数据集上接近最优固定参数（F1 差 0.33pp），FP 47 vs 46。与原始基线
相比，FP 降低 68%、F1 +2.0pp。

**结论**：自适应深度在本数据集（行人集中在 2-10m）上未显著超越固定 depth=6，但其
优势在于**场景泛化**——当传感器安装高度、环境尺度或目标分布变化时，自适应策略无需
手动调整深度参数。对于极端近密远疏场景预期有更大优势。

**原始基线（depth=10, max_pts=20, occ=4）**作为本项目长期参考基准永久保留。
后续任何聚类策略变更均需与此基线对比，确保不出现显著倒退。

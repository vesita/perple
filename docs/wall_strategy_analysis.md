# 墙体提取策略分析

基于 10 帧室内 LiDAR 点云（~16000 非地面点/帧）的对比测试结果。

## 策略一览

| 策略 | 核心思路 | 状态 |
|------|----------|------|
| TopDownCluster | XY 网格化 + BFS 聚类 + 2D PCA | 推荐 |
| XYRansacWall | XY 平面 2D 线 RANSAC | 待测 |
| XYDBSCANWall | XY DBSCAN 密度聚类 | 待测 |
| SequentialFit | 迭代 SVD 平面拟合 | 保留（需修复） |

---

## 已移除策略

### RANSAC 3D 平面拟合（已移除）

移除原因：
- 每次迭代需采样 3 个点拟合 3D 平面，计算量大（25-28ms/帧）
- 固定 max_walls=5 的假设不灵活，无法适应不同房间结构
- 3D 平面拟合对天花板/地面残余敏感，需额外竖直性过滤
- 被 XY RANSAC 线检测替代：2D 线只需 2 个采样点，更稳定更快

历史数据（仅供参考）：
- d=0.20, i=100, n=0.2 → 5 面墙, 15012 墙点, 25.2ms
- d=0.10, i=100, n=0.3 → 5 面墙, 14569 墙点, 28.2ms

### RANSAC + OBB 验证（已移除）

移除原因：
- OBB 验证开销大（+42ms），总耗时 69-125ms/帧
- n=0.30 + d≥0.15 时过度切分：26-27 面碎片墙，>120ms
- OBB 计算需要协方差矩阵 + 特征值分解，复杂度高
- redra 已回滚 OBB 支持，统一使用 AABB

历史数据（仅供参考）：
- d=0.15, n=0.50, nt=0.2 → 5 面墙, 14886 墙点, 68.7ms
- d=0.15, n=0.30, nt=0.2 → 26 面墙, 14907 墙点, 122.5ms（过度切分）

### XY 法线方向聚类（已移除）

移除原因：
- k-NN 搜索性能极差：cell_size=2.0m 导致每格 ~2000 点，排序 6000 候选 × 16000 点
- 即使优化 cell_size 到 0.3m，每帧仍需 ~6 秒，远超 100ms 阈值
- 算法复杂度 O(n² log n)（k-NN 排序），无法在实时场景使用
- 被 XY DBSCAN 替代：同样处理任意朝向，但复杂度 O(n)

## 当前策略

### 1. TopDownCluster（俯视聚类）推荐

XY 平面网格化 → 密集柱体检测 → BFS 合并相邻密集格 → 2D PCA 细长性验证 → 3D PCA 拟合。

#### cell_size=0.05（推荐范围）

| 参数 | 墙面数 | 墙点 | 耗时 | 评价 |
|------|--------|------|------|------|
| d=5, m=1 | 8 | 12571 | 14.2ms | 快，覆盖稍低 |
| d=5, m=2 | 8 | 13547 | 16.0ms | **最佳平衡** |
| d=5, m=3 | 8 | 13624 | 17.9ms | 略慢，覆盖相近 |
| d=3, m=2 | 8 | 14034 | 17.4ms | 覆盖最广 |
| d=8, m=1 | 8 | 12030 | 13.4ms | 最快 |

特点：cell_size=0.05 在所有参数组合下均稳定，墙点 12000-14000，是最安全的选择。

#### cell_size=0.10（有条件可用）

| 参数 | 墙面数 | 墙点 | 耗时 | 评价 |
|------|--------|------|------|------|
| d=5, m=1 | 8 | 13598 | 14.9ms | 大格高覆盖 |
| d=8, m=1 | 8 | 13841 | 14.0ms | **大格最优** |
| d=5, m=2 | 7.8 | 2899 | 11.4ms | 覆盖骤降！ |

特点：cell_size=0.10 仅在 merge_dist=1 时可用。merge_dist≥2 时大格导致过度合并。

#### 参数敏感性

- **cell_size**：最关键参数。0.05 最稳定，0.10 需配合 m=1，0.15 不可用
- **merge_dist**：c=0.05 时 m=2 最佳；c=0.10 时必须 m=1
- **min_density**：5 是合理默认值，3 包含噪声，8 略丢弱墙面

### 2. XYRansacWall（XY RANSAC 线检测）

XY 平面 RANSAC 线检测：采样 2 点 → 拟合 2D 线 → 收集内点 → 验证 Z 跨度。

```
输入：非地面点云

1. 随机采样 2 个 XY 点 → 线方向 (dx, dy)
2. 法线 = (-dy, dx) 归一化
3. 计算所有点到线距离，收集内点（距离 < threshold）
4. 验证内点 Z 跨度 > min_z_span（排除地面/桌面）
5. 内点交换到前部，重复找下一面墙
```

优势：
- 2D 线只需 2 个采样点（vs 3D 平面需 3 个），更稳定
- 天然处理任意朝向（斜墙、弧墙近似为多段线）
- Z 跨度验证排除水平面

参数：
- distance: 点到线距离阈值 (m)，default 0.10
- iterations: RANSAC 迭代次数，default 100
- min_z_span: 墙面最小 Z 跨度 (m)，default 1.0

### 3. XYDBSCANWall（XY DBSCAN 聚类）

DBSCAN 在 XY 平面聚类，每簇验证是否为墙（细长性 + Z 跨度）。

```
输入：非地面点云

1. XY 网格索引，O(n) 邻域查询
2. 标记核心点（邻居数 >= min_pts）
3. BFS 合并连通核心点 → 簇
4. 每簇验证：2D PCA 细长比 + Z 跨度
5. 法线从 2D PCA 最小特征向量提取，nz=0
```

优势：
- 密度聚类，天然处理不规则形状和噪声
- 不需要预设墙面数量
- 可处理点密度不均匀的场景

参数：
- eps: 邻域半径 (m)，default 0.15
- min_pts: 核心点最小邻居数，default 5
- max_width_ratio: 细长比阈值，default 0.3
- min_z_span: 墙面最小 Z 跨度，default 1.0

### 5. SequentialFit（迭代 SVD 拟合）保留

迭代拟合主平面 → 收集内点 → 非竖直平面内点标记为已用 → 重复。

状态：算法已修复（非竖直平面内点正确移除），但尚未重新验证。SVD 可能仍优先拟合天花板/地面。

## 算法对比

| 特性 | TopDown | XY RANSAC | XY DBSCAN |
|------|---------|-----------|-----------|
| 采样方式 | 确定性 | 随机 | 确定性 |
| 朝向处理 | 网格对齐 | 任意 | 任意 |
| 噪声鲁棒 | 中 | 高 | 高 |
| 复杂度 | O(n) | O(iter×n) | O(n) |
| 参数敏感 | cell_size | distance | eps, min_pts |

## 附录：共同验证标准

所有策略的墙面验证都基于以下 XY 平面特征：

1. **细长性**：2D PCA λ_min / λ_max < threshold（墙面在 XY 中是一条线）
2. **Z 跨度**：z_max - z_min > threshold（墙面是竖直的，不是桌面/地面）
3. **竖直性**：|nz| < threshold（法线水平，墙面垂直于地面）

这三个条件从不同角度描述同一特征：**墙面是 XY 平面中的细长竖直结构**。

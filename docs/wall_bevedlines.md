## 2  BevEDLines：基于BEV密度梯度编码的墙体检测方法

### 2.1  问题背景与难点分析

室内结构化场景中墙体具有明显的几何特征：墙面垂直于地面、沿平面分布，在水平投影
面上呈现为线段结构。对于已移除地面的点云，剩余点在水平面上的分布已能反映场景的
主要结构，因此基于水平面投影的线段检测是墙体提取的合理技术路线。

然而，LiDAR 点云投影至 BEV 平面后，远距离墙面区域点云稀疏。若采用传统二值化占
用图处理，这些区域将被直接标记为空，后续线段检测无法产生有效响应。基于点云的几
何方法也存在各自的局限：Hough 变换对稀疏直线有一定鲁棒性，但输出为无限长直线，
缺乏起止信息且易产生冗余峰值；LSD 算法基于全图种子排序，计算量随图像分辨率线性
增长，在资源受限平台上实时性受限。上述问题的核心矛盾在于：如何在保留点云密度分
布信息的同时，实现墙体线段的高效检测。

### 2.2  算法设计

针对上述矛盾，一种自然的思路是保留 BEV 投影中的密度分布信息而非将其二值化。
BevEDLines 基于该思路，通过密度梯度编码保留远距离墙面的有效响应，并利用 Edge
Drawing 链式追踪[3]实现高效边缘提取。其核心流程为：密度编码 → Sobel 梯度计算 →
锚点检测 → 链式追踪 → 线段拟合 → 三维几何验证。具体步骤如下：

**（1）BEV 密度编码。** 将非地面点云投影至 XY 平面，以分辨率 $r = 0.05\text{m}$ 建
立栅格图，每个栅格的密度值为该格内的点数，经对数归一化得到像素值：

$$
I(x, y) = 255 \cdot \log(1 + N(x, y)) / \log(1 + N_{\max}) \tag{1}
$$

对数编码使墙面-地面交界处呈现为连续的梯度过渡带，即使远处稀疏墙面仍能产生有效
梯度响应，这是区别于二值占用图的关键设计。

**（2）Sobel 梯度计算。** 对密度编码图计算 Sobel 梯度，梯度方向以二进制编码标记
（$|G_x| \geq |G_y|$ 为垂直边缘，反之为水平边缘），省去三角函数计算，且与下文
锚点搜索的像素步进方向直接对应。

**（3）锚点检测。** 在梯度幅值场上沿梯度方向检测局部极大值点（Anchor），仅在边缘
附近产生候选点，大幅减少后续计算量。

**（4）Edge Drawing 链式追踪。** 从锚点出发沿边缘方向以 3 像素候选策略（正前方、
45° 侧偏）逐点追踪，直至梯度幅值降至阈值以下或超出图像边界。

**（5）线段拟合与二维过滤。** 每条边缘链经曲率分裂递归切分为近似平直的子段，对
每个子段通过协方差矩阵 PCA 分解求取精确线段参数，过滤长宽比异常的部分。

**（6）三维几何验证。** 将候选线段映射回三维空间，施加 Z 轴跨度 $\geq 1.0\text{m}$、
沿墙投影跨度 $> 0.7\text{m}$ 两项几何约束，抑制地面残留点或小型障碍物引起的误检。

**（7）墙体点输出。** 通过验证的线段所关联的三维点标记为墙面点，同时输出墙面的
平面方程供下游模块使用。

### 2.3  创新点分析

BevEDLines 相比基于投影的墙体检测方法[4]的区别主要体现在三方面：（1）密度梯度
编码取代二值占用图，保留了点云的密度分布信息，使低密度区域仍能产生有效梯度响应；
（2）Edge Drawing 链式追踪仅从锚点出发沿边缘追踪，避免了 LSD 全图种子排序带来
的计算开销；（3）三维几何验证从空间尺度层面对二维线段施加约束，抑制了非墙面
结构引入的误检。
